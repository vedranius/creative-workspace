# SoundCraft original browser UI preview — alpha.47

The unchanged original `storytold/soundcraft` web UI was built from the clean exact upstream v0.7.0 pin `3a28a657692c1b98b28c276d8f61df9471074f0f`. Its upstream entry is `apps/soundcraft-web`, which runs the same `SoundApp` UI as the desktop target. The build used Rust 1.99.0, `wasm32-unknown-unknown`, wasm-bindgen 0.2.129, checksum-pinned Trunk 0.21.14, one Cargo job and `low-impact-build.py`. The initial optimized Rust build completed successfully in 6m23s; Trunk's `wasm-opt -Oz` step then completed without errors. Host priority changes were corrected only for this build process; build processes ran at nice 10.

The package registry records immutable source identity and hashes for every asset. Optimized WASM is 15,496,493 bytes, SHA-256 `71b932a3712190b599dcd9341a689926625ed70c4ed7890431049daac8907654`; JavaScript is 158,155 bytes, SHA-256 `c0bd744aa3ca80ca452bde418cc78cad8521eb12095fabb9a100e167df529c02`. Package ID is the upstream pin. The source's MIT and Apache-2.0 licenses, `NOTICE`, and `ATTRIBUTION.md` are included in provenance; their original root license hashes are `6aff3a3f0d8eb4c2d4fca151a00cdf26d8ff3020889402a453381a12dba3381e` and `0d542e0c8804e39aa7f37eb00da5a762149dc682d7829451287e11b938e94594` respectively. No third-party sample media was added.

An isolated Creative Workspace server on loopback port 33951 used separate temporary data/workspace roots and QA credentials. Chromium for Testing 151.0.7922.34 at 1600×1000 loaded `/original/soundcraft/?webgl` over WebGL2/SwiftShader. The actual original UI rendered its session/transport menus, “Midnight Groove” demo, track list, timeline ruler, waveform and MIDI clips. There were zero page errors, console errors or failed requests. The authenticated registry reported `available: true`, `processing: "browser"`, and `serverIntegrated: false`. [Screenshot](evidence/soundcraft-original-ui.png) and [machine-readable browser report](evidence/soundcraft-original-ui-browser.json).

The upstream web app uses browser WASM for session edits, audio decode/DSP, rendering/export and WebAudio playback. Browser import/export uses browser file pickers and downloads. This preview did not exercise audio playback, a native OS picker, or a real folder permission/write acknowledgement. It does not provide server-owned session/actions, decode/DSP/mix/export, bounded media streaming, a common provider, destination ACK/recovery, native desktop support or full SoundCraft parity. Microphone capture requires explicit browser permissions; WAN live-monitor latency is not established. Keep the catalog entry planned and do not describe this as server processing.

The reproducible build/registration script is `npm run ui:soundcraft:build -- <clean-pinned-source> <static-output> <new-package-root>`. The Actions workflow builds the browser archive and SHA256 sidecar for alpha.47; local archives are evidence only and are not release assets. Verify the Actions run, immutable tag/draft and downloadable asset checksums separately.
