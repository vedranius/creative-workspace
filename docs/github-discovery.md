# GitHub discovery and project identity

The repository is an integration project with explicit original-source credits in the [README](../README.md#original-projects-and-authors), application cards and [license guide](../LICENSE.md). GitHub's “forked from” relationship is one upstream ancestry; it cannot represent simultaneous fork parents for all included projects. Original maintainers do not receive an automatic backlink to this integration.

README names, application links, screenshots and the original [CW logo](brand/logo.svg)/[banner](brand/banner.svg) are part of normal repository content. These are the current discovery/identity surfaces.

## Repository About metadata

The authenticated `vedranius` host token can publish repository content but the About edit returned HTTP 403: `Resource not accessible by personal access token`. Administration permission is separate from content permission. No extra credential is required to read the new documentation; the following concrete About values can be entered by a repository administrator via the GitHub repo's About gear.

**Description**

> Open-source self-hosted creative browser studio integrating RapidRAW and original ArtCraft UI previews: PhotoCraft, VectorCraft, PdfCraft, DesignCraft, LightCraft, FilmCraft and EffectCraft. Independent engines and laptop/server file-provider groundwork.

**Topics**

`self-hosted`, `creative-tools`, `rapidraw`, `artcraft`, `photocraft`, `vectorcraft`, `pdfcraft`, `designcraft`, `lightcraft`, `filmcraft`, `effectcraft`, `webassembly`, `docker`, `agpl-3-0`, `browser-based`, `photography`, `video-editing`, `creative-workspace`.

These labels describe the project and its upstream integrations; they do not turn previews into completed server-backed applications. Visibility in upstream directories, recommended-project lists or their READMEs would require a separately agreed contribution with those maintainers. No such backlink or endorsement is claimed here.
