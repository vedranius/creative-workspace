# FigCraft original browser UI preview — alpha.46

The unchanged original FigCraft v0.6.0 web UI was built from exact clean source pin `833f0d2c27f0acbae5394848930ae531fc89c724` (`storytold/figcraft`, release commit `833f0d2c27f0acbae5394848930ae531fc89c724`). The upstream instructions specify `trunk build --release` in `apps/figcraft-web`; Trunk 0.21.14, Rust 1.99.0, `wasm32-unknown-unknown` and `wasm-bindgen` 0.2.129 produced the static browser app. The build used no optional `craft-fonts` checkout; the upstream build supports that and falls back to system fonts.

The immutable package records the source commit and SHA256 per file, plus MIT/Apache licenses, `NOTICE`, `ATTRIBUTION.md` and the separate ArtCraft mark license. FigCraft's brand terms limit those marks to the original FigCraft context; the package keeps the original context and uses the marks unmodified. Local artifact measurements: optimized WASM 20,859,132 bytes, JavaScript 163,326 bytes, package 21,058,432 bytes, archive SHA256 `c83550a5b5c74ff05c88e35ea3abd93814a1f3002d86a7f25766f496ddee6956`.

An isolated Creative Workspace process on loopback port `49273`, with its own data/workspace roots and QA auth, served the registered package from `/original/figcraft/?webgl`. The roster returned the exact pin, `processing: browser`, `serverIntegrated: false`, and an available preview. Chromium 151.0.7922.173 rendered the complete original interface at 1440×1000 through WebGL2/SwiftShader with no page errors, console errors or failed requests. The original Frame tool (`F`) created a 360×250 frame on the canvas; the original page/layer/property panels updated. Screenshots: [original editor](evidence/figcraft-original-ui.png) and [Frame tool edit](evidence/figcraft-original-edit.png). Browser report: [JSON evidence](evidence/figcraft-original-ui-browser.json).

This web build begins with a blank document. The upstream web README says native open/save dialogs are not wired up; its shared `Services::pick_open` and `pick_save` defaults return no path, so its export/save actions do not yet provide browser file writes. The page's PNG export button was inspected but did not produce a download in this build. This does not establish file-provider behavior, destination acknowledgement, save/reopen/recovery, server-owned document state/actions/layout/render/export, linked asset handling, native OS support or full Figma parity. The original interface and processing remain browser WASM; keep FigCraft planned. No adapter availability claim is made.

Alpha.46 adds immutable registration, the exact-pin build/archive recipe and a dedicated Actions browser archive/checksum job. CI, immutable tag/draft, Actions asset and downloaded checksum verification are pending that run. This archive is a browser preview, not a native creative bundle.
