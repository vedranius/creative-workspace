## Resource and input contract

Parameters must be an object of at most 4 KiB serialized UTF-8. Only original known fields are admitted; original enum values, boolean flags and u32 `startAt` are checked. Prefix, suffix, separator, paragraph/character style and rule color strings are at most 256 UTF-8 bytes each. Space before/between, minimum baseline, rule width and weight are finite 0–10,000 points; rule offset/left indent permit −10,000–10,000 points and tint permits 0–1. Rule fields form an exact known partial object. Original UI invalid-measure omission and separator metacharacter conversion remain unchanged.

Before original composition, the worker checks `startAt + sum(max(note count, reference count)) <= u32::MAX`, reserving the original composer's increment after the final reference and covering cross-story numbering. Options execute first on an isolated COW original Session with the exact document/selection. Existing document/canonical/page/item/story/ID budgets must accept that result before the actual edit/history changes. These are bounded adapter checks, not a claim of complete resource or memory protection. The original upstream command/composition code is unchanged.
