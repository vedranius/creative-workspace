# Original DesignCraft footnote wire and geometry — alpha.69

The original footnote address uses `CellAddr { table: u64::MAX, row: note_id, col: 0 }`. JavaScript rounded that sentinel before the original Rust UI could deserialize selection, leaving the mirror on the previous revision. The owned worker now converts this address to `note: {kind: "footnote", id: "1"}` before protocol JSON serialization, including selection, command results and caret/range metadata. The original document format and engine commands remain unchanged.

The original Rust UI validates the explicit tag, canonical story/note and UTF-8 range, reconstructs the exact native address internally, then accepts the matching ACK. Raw pseudo-table numbers, tag/cell collisions, unknown notes, malformed/zero/leading-zero/overflow IDs and out-of-range selections are rejected. Supported note IDs are 1 through 4294967295, fitting both canonical JSON numbers and wasm32 rows; the native import budget rejects larger IDs before browser parsing. Ordinary table IDs/row/column limits are unchanged.

Caret endpoints use original `note_caret`, which already adds the note origin. Ranges use original `find_note` text/highlight quads, adding the origin once before frame/ancestor transforms. The server clips translucent blue highlights to the selected page; printing/canonical document content is unchanged by selection. Gateway validation matches note and range to both native read-model metadata and canonical snapshot, plus story/frame/page and bounded pixel geometry. The original UI retains its own black caret/blink and ACK ordering.

Native generated three-page facing-document proof checks original hit/select-all/edit-to-Z/body preservation/save/reopen, tagged geometry and sibling clipping. Original UI tests check exact address hydration and refusal of malformed or ambiguous addresses. The isolated fresh-WASM browser smoke passes: actual original Open, left/right thumbnails, note caret ACK4, Ctrl+A range ACK5, held typing ACK6, independent black-caret blink (dark pixels 5→20), unchanged left sibling ACK7 and exact restored caret/PNG ACK8. Native Save a Copy and fresh-worker reopen retain Z and the original body; synthesized input is unchanged. Zero page/console/failed-request/HTTP errors.
