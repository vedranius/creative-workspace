Explore original creative applications in your browser. Images, films, words, sound, and everything in between.

This demo uses your computer. Editing, decoding and rendering run on your laptop’s CPU, GPU and memory, inside the browser. Cloudflare hosts the application files. This demo has no document-upload backend; upstream applications may request fonts or other public resources. Save or download your work before closing a tab.

The full self-hosted project is developing server processing for lightweight laptops. This public playground is a separate browser-processing preview, with no remote desktop.
